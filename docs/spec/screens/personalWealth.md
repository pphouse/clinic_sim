# 画面仕様：個人資産

> ステータス: **実装済み**
> ScreenId: `personalWealth`
> 領域色: `hq`

## この画面の唯一の仕事

役員報酬をいくら取るかを決め、貯まった個人資産で見栄を張る。

## ★法人の数字に一切効かせない

役員報酬は法人の費用なので、**取れば取るほど法人の利益と現金は減る。**
そこまでは普通のトレードオフ。だが個人が何を買うかは法人に効かない。

効かせたくなる。「クルーザーを買うと医師会での評判が上がる」は書ける。
書かない理由は 1 つで、**嘘の因果ができるから。** 見栄レイヤーは進捗を測る
物差しであって、意思決定ではない。`expansion.test.ts` に
「見栄資産は法人の数字に一切効かない」という試験を置いて固定してある。

## 表示するデータ

| 表示名 | sim のフィールド | 書式 |
|---|---|---|
| 個人資産 | `expansion.personal.netWorth` | 万円 |
| 称号 | `expansion.personal.rank` | ラベル |
| 役員報酬 | `expansion.personal.salary` | 万円/月 |
| 手取り | `expansion.personal.netSalary` | 万円/月 |
| 累計報酬 | `expansion.personal.cumulativeSalary` | 万円 |
| 買えるまで | `monthsToAfford(price, cash, netSalary)` | ヶ月 |
| 推移 | `personalNetWorthSeries(history, month, 24)` | 折れ線 |

「買えるまであと◯ヶ月」が要る。**手が届かないものに、届くまでの距離を出す。**

## プレイヤーができること

| 操作 | 効果 | 反映されるまでの遅延 |
|---|---|---|
| 役員報酬を上げる／下げる | 法人の費用が動く。上限 300 万/月 | 即時 |
| 見栄資産を買う | 個人現金が減り、称号が上がる | 即時 |

## NPC の挨拶文

| 条件 | 文言 |
|---|---|
| 通常 | 「先生の個人口座は ◯◯万円です」 |
| 報酬 0 | 「役員報酬を取っていらっしゃいませんね」 |
| 法人が赤字 | 「法人が赤字です。報酬を下げるという手もあります」 |

## 通知バッジを出す条件

出さない。**この画面には急ぐ用事が無い。** バッジは行動を促す道具なので、
行動しなくていい画面に出すとバッジ全体が軽くなる。

## やらないこと

- 個人資産を法人に効かせる（上記）
- 相続・事業承継。10年では射程外
- 個人の投資運用。もう1つ別のゲームになる
