# 画面仕様：不動産

> ステータス: **実装済み**
> ScreenId: `realEstate`
> 領域色: `bank`（緑。金の話なので銀行と同系）

## この画面の唯一の仕事

テナントを借り続けるか、物件を買うか。**現金 9,000 万を今出して、
月 75 万の家賃を永久に止める。**

## 判断の中身

| | テナント | 自社保有 |
|---|---|---|
| 現金 | 出ていかない | 9,000 万が一度に出る |
| P/L | 地代家賃が毎月 | 家賃が半分消え、建物の償却が乗る |
| B/S | 載らない | 建物として載る（20年償却） |

**回収年数は `propertyPaybackYears()` が出す。** 単純な割り算で、
値上がり益も割引現在価値も見ない。見せかけの精度を足さない。

## 表示するデータ

| 表示名 | sim のフィールド | 書式 |
|---|---|---|
| 消えた家賃 | `expansion.realEstate.rentSaved` | 万円/月 |
| 保有物件の簿価 | `expansion.realEstate.bookValue` | 万円 |
| 院ごとの状況 | `expansion.realEstate.properties[]` | 一覧 |
| 回収年数 | `propertyPaybackYears(rentSaved)` | 年 |
| 手元現金 | `financials.balanceSheet.cash` | 万円 |

最後の行が要る。**買えるかどうかは、買うべきかどうかより先に決まる。**

## プレイヤーができること

| 操作 | 効果 | 反映されるまでの遅延 |
|---|---|---|
| 物件を取得する | 現金 −9,000、翌月から家賃が半減 | 1ヶ月 |

売却は実装しない。**含み損益を出すと会計が一段複雑になる割に、判断が増えない。**


## NPC の挨拶文

| 条件 | 文言 |
|---|---|
| 通常 | 「◯院の物件、オーナーが手放したいそうです」 |
| 現金が足りない | 「◯◯万円足りませんね。銀行と相談されてはいかがです」 |
| 保有済み | 「家賃のご心配が要らないのは強いですよ」 |

## 通知バッジを出す条件

- 保有物件がある状態で現金が 1,000 万を割った（warning）

## やらないこと

- 賃貸に回して家賃収入を取る（それは門前薬局が担当している）
- 立地の良し悪しを数値化する。開院時の患者ポテンシャルで既に表現されている
- 売却・時価評価
