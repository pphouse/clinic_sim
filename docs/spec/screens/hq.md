# 画面仕様：本社

> ステータス: **実装済み**
> 担当ブランチ: `feature/screen-hq`
> ScreenId: `hq`
> 領域色: `hq`

## この画面の唯一の仕事

**全社がいま黒字か、現金が保つか**を一目で示す。細部は経理・人事・銀行が持つ。

## 表示するデータ

sim から読む値だけを列挙する。UI で計算しない（CLAUDE.md §2）。

| 表示名 | sim のフィールド |
|---|---|
| 通院患者 | `totalPatientStock(result)` |
| 現金 | `balanceSheet.cash` |
| 純資産 | `balanceSheet.totalEquity` |
| 診療収入・学費収入 | `deriveGroupTotals()` |
| 診療所の営業利益／学校の収支 | 同上 |
| 本部費 | `hqCost`（本部費＋医局維持費＋紹介手数料） |
| 開院数・常勤医・看護師・有利子負債 | `clinicSummaries()` / `StaffTick` / `totalDebt()` |

**ここの営業利益は検証モデルの定義**で、本部費・金利・減価償却を含まない。
発生主義の営業利益とは値が違うので、画面に注記を出す。混同されると会計が信用されなくなる。

## プレイヤーができること

無し。本社は読む画面。意思決定はそれぞれの建物で行う。

## やらないこと

- **意思決定。** どこで何を決めたかが曖昧になる
- **三表。** それは経理の仕事。ここは要約だけ
