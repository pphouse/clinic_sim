# 画面仕様：銀行

> ステータス: **実装済み**
> 担当ブランチ: `feature/screen-bank`
> ScreenId: `bank`
> 領域色: `bank`

## この画面の唯一の仕事

**資金ショートと債務超過を区別して見せる。** この2つは別物。

## 表示するデータ

sim から読む値だけを列挙する。UI で計算しない（CLAUDE.md §2）。

| 表示名 | sim のフィールド |
|---|---|
| 現金 | `balanceSheet.cash` |
| 借入残高（短期／長期） | `shortTermDebt` / `longTermDebt` |
| 純資産 | `totalEquity` |
| 新規借入・元金返済 | `CashFlowStatement` |
| 支払利息 | `IncomeStatement.interestExpense` |

**判定を2行で並べる。**
現金 < 0 は資金ショート（つなぎ融資で越えられる）、純資産 < 0 は債務超過（ゲームオーバー判定）。
既定シナリオは28ヶ月目に前者、34ヶ月目に後者へ入る。

## プレイヤーができること

| 操作 | 効果 | 制約 |
|---|---|---|
| 5,000万を借りる | 現金が増え、翌月から利息と元金返済が乗る | 純資産の **4倍** まで |

★**債務超過なら1円も引けない。** 落ちてから借りて延命する、ができないようにしてある。
枠が残っていなければボタンは「融資枠がありません」になる。

開院と開校に紐づく融資は従来どおり自動（候補地ごとに額が違う）。

## やらないこと

- **金利の交渉。** 検証モデルに無い
- **返済スケジュールの変更。** 同上
