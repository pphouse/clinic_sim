# 画面仕様：マップ

> ステータス: **プロトタイプ実装済み**
> 担当ブランチ: `feature/screen-map`
> ScreenId: `map`
> 領域色: `-`（世界であって建物ではない。領域色は持たない）

## この画面の唯一の仕事

**どこが詰まっているかを一目で示し、そこへ入らせる。**

数字を読ませる画面ではない。「A院の待ち時間が跳ねている」を**地図の上で**分からせて、
タップさせるところまでが仕事。細部は診療所画面が持つ。

## 他の画面との関係

マップは**根**であって、モーダルではない。ここだけは `×` で閉じられない。

```
マップ ──タップ──▶ 診療所（全画面差し替え）──×──▶ マップ
```

CLAUDE.md §5 の「モーダルは全画面差し替え」はこの往復のこと。
マップに戻るのが唯一の帰り道なので、**マップは常に全社の現在地を持っていること。**

## 表示するデータ

sim から読む値だけを列挙する。UI で計算しない（CLAUDE.md §2）。

### 全社サマリ（画面上部）

| 表示名 | sim のフィールド | 書式 |
|---|---|---|
| 通院患者 | `totalPatientStock(result)` | 人・整数＋前月比 |
| 現金 | `financials.balanceSheet.cash` | 万円＋前月比 |
| 営業利益 | `deriveGroupTotals(result).operatingIncome` | 万円・当月 |

**現金を全社サマリに出すのは、この画面が「資金ショートに気づく場所」だから。**
既定シナリオは28ヶ月目に現金がマイナスへ沈む。診療所画面には現金が無いので、
ここに出ていないと誰も気づかないまま10年が終わる。

### 地図上の各院（`clinicSummaries(result)`）

| 表示 | sim のフィールド |
|---|---|
| ピンの位置 | `ClinicConfig` の固定座標（`MAP_POSITIONS`。sim は座標を持たない） |
| 混雑の色 | `waitMinutes` を `TOLERABLE_WAIT_MINUTES` / `CRITICAL_WAIT_MINUTES` で3段階 |
| 通知バッジ | `eventsForScreen(result, 'clinic')` のうちその院のもの |
| 未開院 | `openMonth > 現在月` のとき灰色＋開院月 |

### 各院のカード（地図の下）

| 表示名 | sim のフィールド | 書式 |
|---|---|---|
| 院名 | `ClinicConfig.name` | — |
| 通院患者 | `ClinicTick.patientStock` | 人 |
| 待ち時間 | `ClinicTick.waitMinutes` | 分・小数1桁。混雑色 |
| 評判 | `reputationStars(reputation)` | 星5段階 |
| 常勤医 | `StaffTick.doctorsByClinic[id]` | 名 |

**他院との比較はここでやる。** 診療所画面ではやらない（clinic.md「やらないこと」）。
横並びで見て初めて「B院だけ空いている」が分かるので、比較はこの画面の仕事。

## プレイヤーができること

| 操作 | 効果 | 遅延 |
|---|---|---|
| 院をタップ | 診療所画面へ全画面差し替え | 即時 |
| 月を進める / 戻す（1ヶ月・1年） | 表示月が変わる | 即時（表示のみ） |

**マップに意思決定は置かない。** 医師の増減は診療所、投資は各建物。
マップで直接いじれると「どこで何を決めたか」が曖昧になる。

## 混雑の3段階

| 状態 | 条件 | 色 |
|---|---|---|
| 平常 | `waitMinutes ≤ TOLERABLE_WAIT_MINUTES` | `--hq-accent` |
| 警告 | 超過 | `--warning` |
| 危機 | `waitMinutes ≥ CRITICAL_WAIT_MINUTES` | `--critical` |

しきい値は sim の定数をそのまま使う。**UI で 20 や 45 を直書きしない。**

## やらないこと

- **意思決定。** 上記のとおり
- **時系列グラフ。** 推移は診療所画面の仕事。マップは「今どこが赤いか」だけ
- **未実装の建物をピンとして出す。** 仕様の無い画面へは行けないので、行けない先を
  地図に描かない（CLAUDE.md §7）。医局も銀行も、仕様を書いてから地図に載せる
- **地図のスクロールとズーム。** 縦持ち1画面に収める。3院が16棟になったら考える
