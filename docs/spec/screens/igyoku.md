# 画面仕様：医局

> ステータス: **実装済み**
> 担当ブランチ: `feature/screen-igyoku`
> ScreenId: `igyoku`
> 領域色: `igyoku`

## この画面の唯一の仕事

**関係値は金では買えない**ことを、画面の形で分からせる。

## 表示するデータ

sim から読む値だけを列挙する。UI で計算しない（CLAUDE.md §2）。

| 表示名 | sim のフィールド |
|---|---|
| 関係値（0〜120） | `StaffTick.igyokuRelation` |
| 派遣枠 | `StaffTick.igyokuSlots` |
| 維持費 | `IncomeStatement.igyokuRelationCost` |
| 紹介会社に頼っている数 | `doctorsTotal − igyokuSlots` |

関係値はゲージで出す。**次の枠まであといくつか**が見えないと、
「払っているのに増えない」がただの理不尽になる。

## プレイヤーができること

| 操作 | 効果 |
|---|---|
| 維持費の支払い | 関係値が据え置きになる。**払わないと毎月 0.67 ずつ下がる** |
| 当直を出す | 関係値が毎月 +1。代わりに**診察枠が 5% 落ちる** |

★**調達可能数（派遣枠＋紹介会社の累計）を超えて医師は置けない。**
超えた分は「採用できていない空席」として消え、人件費も診察枠も発生しない。
診療所画面の ＋ ボタンもそこで止まる。押せてから無視されるのがいちばん分かりにくい。

★当直が「金では買えない関係を、枠で買う」手段。
外部関係の3画面と同じ「続けると育ち、やめると止まる」形にしてある。

維持費は「下がらないようにする」ための費用であって、上げるためのものではない。
上げるのは当直の引き受けや症例の還元といった非金銭的な貢献（`igyokuRelationDelta`）。


## やらないこと

- **金で関係値を上げる導線。** これを入れると医局と紹介会社の区別が消える
- **医師個人の指名。** 人数しか持たない
