# 画面仕様：門前薬局

> ステータス: **実装済み**
> ScreenId: `pharmacy`
> 領域色: `pharmacy`（緑）

## この画面の唯一の仕事

敷地に薬局を誘致して賃料を取る。**診療とは別系統の、CFの谷を埋める安定収入。**

## 完全な安定収入にはしない

```
賃料 = 定額 60万 ＋ 患者数 × 0.008万
```

歩合を混ぜてあるのは、**患者が減れば賃料も減る**ようにするため。
完全な固定収入にすると「開院したら必ず誘致」が最適解になって判断が消える。
一時金 1,200 万を先に払うので、患者が育つ前に誘致すると回収が遅れる。

## 表示するデータ

| 表示名 | sim のフィールド | 書式 |
|---|---|---|
| 今月の賃料 | `expansion.pharmacy.rentalRevenue` | 万円/月 |
| 院ごとの賃料 | `expansion.pharmacy.pharmacies[].rent` | 万円/月 |
| 誘致月 | `expansion.pharmacy.pharmacies[].invitedAtMonth` | ◯年目◯月 |
| 一時金 | `PHARMACY_INVITE_CAPEX` | 万円 |
| 賃料の推移 | `pharmacyRentSeries(history, month, 24)` | 折れ線 |

## プレイヤーができること

| 操作 | 効果 | 反映されるまでの遅延 |
|---|---|---|
| 誘致する | 一時金を払い、翌月から賃料が立つ | 1ヶ月 |

一度誘致したら解除しない。**引き剥がす操作は現実にも無い。**

## レイアウト

```
[アイコン] 門前薬局
──────────────────
イラスト帯 ＋ NPC
──────────────────
今月の賃料（大） 誘致数 一時金
賃料の推移（折れ線）
院ごとの状況
──────────────────
[◯院に誘致する]（操作卓）
```

## NPC の挨拶文

| 条件 | 文言 |
|---|---|
| 通常 | 「今月の賃料は ◯◯万円です」 |
| 未誘致の院がある | 「◯院の隣、まだ空いていますよ」 |
| 患者が減っている | 「処方箋が減っていますね。歩合の分が下がります」 |

## 通知バッジを出す条件

- 賃料が前年同月を下回った（info）

## やらないこと

- 薬局の経営そのもの（在庫・薬価差益）。**この画面はテナントオーナーの視点**
- 敷地内薬局の規制論。制度の是非はゲームの題材にしない
