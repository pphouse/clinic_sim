# 画面仕様：経理

> ステータス: **実装済み**
> 担当ブランチ: `feature/screen-accounting`
> ScreenId: `accounting`
> 領域色: `hq`

## この画面の唯一の仕事

**三表を出す。** そして貸借が合っていることを毎月示す。

## 表示するデータ

sim から読む値だけを列挙する。UI で計算しない（CLAUDE.md §2）。

3タブ構成（`損益` / `貸借` / `資金`）。docs/spec/02-accounting.md がモデルの仕様。

| タブ | 出すもの |
|---|---|
| 損益 | `IncomeStatement` の全行。収益・費用・利益の3節に割る |
| 貸借 | `BalanceSheet`。資産／負債・純資産の2節。**貸借差額を必ず出す** |
| 資金 | `CashFlowStatement`。営業・投資・財務 |

貸借差額は 0 でなければ会計の実装が壊れている（`assertBalanced`）。
**画面に出しておくと、壊れたときに誰かが気づく。**

## プレイヤーができること

無し。読む画面。

## やらないこと

- **期間の集計（四半期・通期）。** 月次だけ。期間切替は要求が出てから
- **繰越欠損金。** 未モデル化（02-accounting.md）
