# 画面仕様：地域医師会

> ステータス: **実装済み**
> ScreenId: `medicalAssociation`
> 領域色: `shikai`（臙脂）

## この画面の唯一の仕事

休日当番医・学校医・自治体健診の受託を決める。**受託は収入になるが診察枠を食い、
分院を出すと関係が落ちる。** 拡大そのものに効く成長ブレーキ。

## なぜ「開院の許可」にしなかったか

当初は「関係値が 50 を割ると開院できない」という案だった。やめた理由は 2 つ：

1. 検証済みの既定シナリオは 19・43 ヶ月目に開院する。関係値で止めると
   開院月がずれ、`baseline.golden.json` と突き合わせられなくなる（CLAUDE.md §1）
2. 「許可が下りるまで待つ」は判断ではなく待ち時間になる

代わりに**受託の閾値**にした。関係を積めば仕事が回ってくるが、その仕事は
自院の診察枠を削る。積まなければ何も起きない。どちらも選べる形にしてある。

## 表示するデータ

| 表示名 | sim のフィールド | 書式 |
|---|---|---|
| 関係値 | `expansion.relations.relations[medicalAssociation].value` | 0〜100 |
| 受託収入 | `financials.incomeStatement.contractRevenue` | 万円/月 |
| 当番で削れる枠 | `expansion.capacityMultiplier` | % |
| 活動費 | `EXTERNAL_RELATIONS[medicalAssociation].monthlyCost` | 万円/月 |
| 推移 | `relationSeries(history, 'medicalAssociation', month, 24)` | 折れ線 |

## プレイヤーができること

| 操作 | 効果 | 反映されるまでの遅延 |
|---|---|---|
| 活動を続ける／やめる | 続けると +1.5/月、やめると −0.5/月 | 即時（値）／閾値までは数年 |

分院を開いた月は −8。**これは操作ではなく、拡大の副作用として起きる。**


## NPC の挨拶文

| 条件 | 文言 |
|---|---|
| 通常（活動中・閾値未満） | 「あと ◯pt で当番医の枠が回ってきます」 |
| 受託中 | 「今月の当番、学校健診と合わせて ◯◯万円です」 |
| 分院を開いた直後 | 「先生のところ、また増やされたそうで。会でも話題になっていましたよ」 |
| 活動していない | 「最近お顔を見ませんね」 |

3行目が効く。**拡大を祝ってくれない相手が1人いる。**

## 通知バッジを出す条件

- 関係値が閾値を割った（warning）
- 分院の開院で関係値が落ちた（info）

## やらないこと

- 開院の可否を関係値で止める（上記の理由）
- 医師会を通じた医師の紹介。それは医局と紹介会社の仕事で、被る
