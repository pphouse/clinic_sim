## 1. 何が起きているか

**どの筋も49ヶ月で破綻する。** 目標は1つも達成できない。

それも純資産 −1.83億で終わる。

## 2. なぜか

### 検証済みモデルの利幅が薄い

検証済みシナリオの12ヶ月目、A院1院だけが開いている状態：

```
患者 3,275人  売上 1,582万/月  費用 1,464万/月  営業利益 +118万/月（利益率 7%）
  内訳：医師人件費 500 ／ 看護師 313 ／ 家賃 150 ／ 本部 83 ／ 材料費 ほか
```

**利益率が7%しかない。**

### 認知度が恒久的に12〜40%削る

認知度の落ち着き先は不動点 `(基礎 + 広告の到達) / (1 − 口コミ)` で決まる。
現在の値（基礎 0.40・口コミ 0.20）だと：

| 広告 | 費用 | 患者が付いた状態の認知度 | 成熟後の月次損益 |
|---|---|---|---|
| なし | 0万 | 0.60 | −445万 |
| チラシ | 25万 | 0.75 | −232万 |
| Web | 70万 | 0.88 | −72万 |
| 大々的に | 160万 | 0.98 | −4万 |

**どの段階を選んでも成熟後が赤字。** 7%の利幅に12%の恒久税をかけたので当然そうなる。
その上、立ち上がりの4年で1.5〜2億の穴を掘るので、二度と埋まらない。

### 原則を破っていた

CLAUDE.md の考え方は「**遊びの層は検証済みの層から引くことしかできない**」で、
既定シナリオでは係数1の恒等式になるように作ってきた。
認知度もその形（既定シナリオは常に1）にはなっているが、
**本編では正しく打っても 0.88 までしか戻らない**。
薄い利幅に対しては、これは「引く」ではなく「殺す」だった。

## 3. 試したこと（いずれも main には入れていない）

### ① 認知度の上限を、正しく打てば 1.0 に戻す

口コミを上げて `Web広告 + 患者が付いた状態 = 1.00` になるようにする。
広告の段階の違いは**立ち上がりの速さ**に出て、成熟後の差は付けない。

→ 1院は120ヶ月生き残るようになったが、純資産 −1.85億で終わる。**分院は依然として全滅。**

### ② 院長を人件費に載せない

**現在のモデルは院長に二重に払っている。** 常勤医3名ぶんの人件費を計上した上で、
別に役員報酬も取れる。自分で開業した院の院長は自分なので、報酬は役員報酬の側にある。

`ClinicConfig.ownerDoctor`（開業で建てた1院目だけが持つ任意項目）で
常勤医1名分を人件費から外す。分院の院長は雇うので普通に人件費。
シナリオが直接持っている院には付かないので、ゴールデンテストは緑のまま。

→ 1院（医師2名・Web広告）が **120ヶ月生き残って純資産 +3,764万**。初めて成立した。
→ **それでも分院を1つ足すとどの時期・規模でも破綻する**（37・49・61・73ヶ月 × 医師1〜3名の12通り、全滅）。

### ③ ①と②を入れた上で、認知度の配分を振り直す

看板だけの院が生き残ってしまい「集患に困る」が壊れたので、基礎を下げて口コミを上げた。
今度は科ごとの立地の差が消え、`specialty.test.ts` の性質が2つ壊れた。

**定数を1つ動かすたびに別の性質が壊れる状態**なので、ここで手を止めた。

## 4. 決めないと先へ進めないこと

分院が立たない理由ははっきりしている。**分院1つの設備投資5,500万に対して、
成熟後の利益が月118万しかない。** 立ち上がりの穴を含めると回収に8年かかる。
10年のゲームで「増やす」が成立しない。

選べる道は3つあって、これは**このゲームが何であるかの選択**なので勝手に決めない。

| | 中身 | 代償 |
|---|---|---|
| A | 分院の投資額と規模を下げる（小さく始める院を用意する） | 候補地・枠・設備投資を一式作り直す |
| B | 目標値を、実際に届く水準まで下げる | 到達点が「10年やって純資産をプラスにする」程度になり、拡大する遊びがほぼ消える |
| C | 1院を育てきる遊びに寄せる（分院は終盤の選択肢にする） | 「医療グループ経営」という題目を変えることになる |

★どれを選んでも、**検証済みの層（`01-simulation-core.md` / `02-accounting.md`）には触らない。**
利幅が7%しかないのは検証済みモデルの性質であって、直す対象ではない。

## 5. 測り方の注意（次に測る人へ）

- 選択肢の損得を**終局までの差**で測ると交絡する。医師を引き止めると翌月以降の
  退職判定の引き数が変わり、乱数列がずれて**別の未来**と比べることになる。
  24ヶ月の窓で測り、状態（待ち時間・月）で条件付ける
- 見たいのは平均の損得ではなく、**符号が状態で変わるか**（＝正解が無いか）
- 実測用のスクリプトは `packages/sim/` に置いて使い、**測り終えたら消す**
