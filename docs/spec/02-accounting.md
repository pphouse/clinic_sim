# 仕様：会計レイヤー（P/L・B/S・C/F）

検証に使ったエクセルには **B/S が無かった。** P/L とキャッシュフローだけで、
しかも開業投資を即時費用処理していた（現金から引いて終わり）。
医療では致命的な省略なので、ここで新設する。

## なぜ B/S が要るのか

**1. 看護学校の 2.5 億は費用ではなく資産**

エクセルでは学校投資が純粋な現金流出として扱われ、「最低現金 −1.8 億」という
結果になった。だが校舎は固定資産なので、純資産は毀損していない。
B/S を入れると、あれは債務超過ではなく**単なる資金繰りの谷**だったと分かる。
プレイヤーへの見せ方が変わる（絶望ではなく、つなぎ融資で越えられる山）。

**2. レセプトは 2 ヶ月遅れで入金される**

保険診療の請求は翌月10日提出、入金は翌々月。約 0.67 四半期分が
医業未収金として常に滞留する。これがあると
**「黒字なのに現金が無い」が自然に発生する。**
Coffee Inc のキャッシュフロー破綻の恐怖を、医療の実態で再現できる。

**3. 減価償却が加算の投資判断に効く**

医療機器を買った四半期に全額が費用になると、加算取得の意思決定が歪む。
5 年で償却されるからこそ「初期投資は重いが、効果は長く続く」が成立する。

## 耐用年数

| 資産 | 四半期 | 年 |
|---|---|---|
| 医療機器 | 20 | 5 |
| 内装 | 40 | 10 |
| 校舎 | 80 | 20 |

開業投資 6,000 万円は 医療機器 60% / 内装 40% に按分する。定額法。

## 不変条件

```
totalAssets === totalLiabilities + totalEquity
```

`assertBalanced()` で毎四半期検証する。**丸め誤差（0.01 万円）を超える差は必ずテストを落とす。**
ここが崩れたまま進むと、後から原因を特定できなくなる。

## ゲームオーバー判定

| 状態 | 判定 |
|---|---|
| 現金 < 0 | 資金ショート。つなぎ融資が引ければ継続 |
| 純資産 < 0 | 債務超過。ゲームオーバー |

エクセルでは前者しか見ていなかった。B/S があるとこの 2 つを区別できる。

## UI

Coffee Inc と同じ 3 タブ構成。

```
[損益計算書] [貸借対照表] [キャッシュフロー計算書]
[週間] [四半期] [通期]
```

列は **2 期比較まで。** モバイルで横スクロールさせない（CLAUDE.md §5）。
3 期以上見たいときは期間切替タブで解決する。
