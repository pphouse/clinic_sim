# 仕様：会計レイヤー（P/L・B/S・C/F）

検証に使ったエクセルには **B/S が無かった。** P/L とキャッシュフローだけで、
しかも開業投資を即時費用処理していた（現金から引いて終わり）。
医療では致命的な省略なので、ここで新設する。

## なぜ B/S が要るのか

**1. 看護学校の 2.5 億は費用ではなく資産**

エクセルでは学校投資が純粋な現金流出として扱われ、「最低現金 −1.8 億」という
結果になった。だが校舎は固定資産なので、純資産は毀損していない。
B/S を入れると、あれは債務超過ではなく**単なる資金繰りの谷**だったと分かる。
プレイヤーへの見せ方が変わる（絶望ではなく、つなぎ融資で越えられる山）。

**2. レセプトは 2 ヶ月遅れで入金される**

保険診療の請求は翌月10日提出、入金は翌々月。**常に2ヶ月分**が
医業未収金として滞留する。刻みを月にしたことで、四半期モデルの 0.67四半期 という
半端な値が実態そのものになった。これがあると
**「黒字なのに現金が無い」が自然に発生する。**
Coffee Inc のキャッシュフロー破綻の恐怖を、医療の実態で再現できる。

**3. 減価償却が加算の投資判断に効く**

医療機器を買った四半期に全額が費用になると、加算取得の意思決定が歪む。
5 年で償却されるからこそ「初期投資は重いが、効果は長く続く」が成立する。

## 耐用年数

| 資産 | 月 | 年 |
|---|---|---|
| 医療機器 | 60 | 5 |
| 内装 | 120 | 10 |
| 校舎 | 240 | 20 |

開業投資 6,000 万円は 医療機器 60% / 内装 40% に按分する。定額法。
**償却は取得の翌月から始まる**（取得月は落とさない）。

加算の取得費（800〜2,500 万円）も医療機器として資産計上する。
即時費用にすると「初期投資は重いが効果は長く続く」が成立せず、取得の判断が歪む。

## まだモデル化していないもの

| 項目 | 現状 | 理由 |
|---|---|---|
| 仕入債務（買掛金） | 0 | 検証モデルに支払サイトの前提が無い。入れるなら先にここへ書く |
| 棚卸資産 | 0 | 同上。B/S に入れるなら C/F の増減も同時に入れること |
| 繰越欠損金 | 無し | 赤字の月は税0、黒字の月はその月だけで課税している |

**棚卸資産を入れるときは C/F の運転資本増減も必ず同時に入れる。**
片方だけ入れると貸借が合わなくなる。

## 不変条件

```
totalAssets === totalLiabilities + totalEquity
```

`assertBalanced()` で毎月検証する。**丸め誤差（0.01 万円）を超える差は必ずテストを落とす。**
ここが崩れたまま進むと、後から原因を特定できなくなる。

## ゲームオーバー判定

| 状態 | 判定 |
|---|---|
| 現金 < 0 | 資金ショート。つなぎ融資が引ければ継続 |
| 純資産 < 0 | 債務超過。ゲームオーバー |

エクセルでは前者しか見ていなかった。B/S があるとこの 2 つを区別できる。

### 既定シナリオを発生主義で組み直した結果

**現金は28ヶ月目にマイナスに沈み、純資産は34ヶ月目にマイナスになる。**
（四半期モデルでは Q10・Q12。刻みを変えても結論は動かなかった。）

| 見方 | 期末（120ヶ月目） |
|---|---|
| 検証モデル（投資を即時費用、未収金・税金なし） | 現金 −4,281 万 |
| 実装の B/S | 現金 −14,987 万／固定資産 15,818 万／純資産 −12,877 万 |

差は未収金（6,771 万）と累計法人税（約 3,935 万）。
資産計上のおかげで純資産は「投資を即時費用処理した見方」より約 1.2 億ぶん良く出るが、
**それでも既定シナリオは債務超過に入る。** 減価償却・本部費・支払利息が薄い営業利益を
食い切っている。B/S を入れた目的がまさにこれを可視化することなので、
34ヶ月目という数字は `simulation.test.ts` に回帰防止として固定してある。

「学校投資は資金繰りの谷であって債務超過ではない」という当初の見立ては、
**谷の部分だけが正しい**（28〜33ヶ月目は現金マイナス・純資産プラス＝つなぎ融資で越えられる）。
既定シナリオ全体は投資過多であり、シナリオ側の判断を見直す余地がある。

## UI

Coffee Inc と同じ 3 タブ構成。

```
[損益計算書] [貸借対照表] [キャッシュフロー計算書]
[月次] [四半期] [通期]
```

列は **2 期比較まで。** モバイルで横スクロールさせない（CLAUDE.md §5）。
3 期以上見たいときは期間切替タブで解決する。
