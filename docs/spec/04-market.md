# 商圏と競合

検証済みのモデル（`01-simulation-core.md`）には競合が居ない。
各院が独立した `newPatientPotential` を持つだけで、
**隣に分院を出しても本院の患者は1人も減らなかった。**

この文書はその上に載る**遊びの層**。数値は検証されていない。

---

## 1. 何を変えるか

```
これまで： 新規患者 = ポテンシャル × 評判/75
これから： 新規患者 = ポテンシャル × 評判/75 × シェア
```

`newPatientPotential` の意味を **「その商圏を独占したときの新規患者数」** に読み替える。
競合が居ればシェアを取られ、居なければシェア 1 で従来どおり。

★**この形だから検証済みの結果が動かない。**
既定シナリオは A・B・C を別々の商圏に置き、競合を1軒も置かない。
商圏に自院1つ・競合0なら シェア = 自院の魅力 / 自院の魅力 = 1 で恒等式になる。

## 2. シェアの決まり方

```
魅力 = 評判 × 待ち時間ペナルティ × 規模係数
待ち時間ペナルティ = 許容待ち時間 / (許容待ち時間 + 超過分)
規模係数 = 1 + 0.2 × (常勤医 − 1)   上限 2.5

シェア = 自院の魅力 / （その商圏の全ての魅力の合計）
```

- 待ち時間が許容内なら待ちペナルティは 1。混むほど落ちる
- ★**規模係数が無いと競合を押し出せない。** 評判は 75 へ回帰するだけで
  それを超えないので、評判だけだと魅力の上限が 75 になり、
  strength 70 の相手をどうやっても 30% 未満に落とせない
- 医師を増やして押し出すのは、過剰人件費を1年半払って
  相手のシェアを丸ごと取る投資。**割に合わないように見えて、割に合う**
- 競合の魅力は `strength`（20〜100。評判に相当する固定値）
- **同じ商圏の自院同士も分母に入る。** 隣に出せば食い合う

### ★魅力の合計が 0 のときはシェアも 0

医師が0名の院は魅力が 0（「看板だけの院に患者は来ない」）。
そのセグメントに他に誰も居なければ、分母が 0 になる。

**ここは等分に落とさず、シェア 0 を返す。**
以前は `1 / 参加者数` で等分していたので、競合の居ないセグメントに
医師0名の院を出すとシェア 1 が渡り、診察できないのに新規患者が入っていた。
独占のときだけ「看板だけの院に患者は来ない」が破れていたことになる。

医師を1人でも置けば魅力が立つので、独占のシェアは 1 に戻る。

### ★前月の値で計算する

シェアは**前月の評判と待ち時間**から出す。今月の待ち時間は今月の需要で決まり、
需要はシェアで決まるので、今月の値を使うと循環する。

遅らせるのは逃げではない。口コミは遅れて効くし、
新規患者が既に「3ヶ月前の評判」で決まっているのと同じ思想。

## 3. 競合

| 性質 | 内容 |
|---|---|
| 見える | 地図に出る。名前・強さ・シェアが分かる |
| 増える | 突発事象で商圏に1軒増える |
| 減る | **シェアを18ヶ月続けて 30% 未満に抑え込むと撤退する** |
| 反応しない | こちらの動きに合わせて強さを変えたりはしない |

撤退があるので、評判を上げることが初めて「奪って、追い出す」まで繋がる。
**評判はこれまで自院の新規患者にしか効いていなかった。**

競合をAIとして能動的に動かすことはしない。10年で数院の話には過剰で、
「相手の手を読む」ゲームにするとテーマが経営から対戦へずれる。

### 突発事象の作り替え

これまでの「競合開業 → ポテンシャルが恒久的に −15%」は廃止する。
商圏に1軒増える形にすれば、**減り幅はシェアの計算から自然に出る**。
係数で殴ると二重に効くうえ、なぜ減ったのかが画面から読めない。

## 4. 商圏の割り当て

| 商圏 | 独占時の新規患者 | 自院になりうる | 最初から居る競合 |
|---|---|---|---|
| 本町 | 260/四半期 | A院（本院）・D院（承継） | 本町内科 70 |
| 駅前 | 350/四半期 | B院 | 駅前メディカル 82・さくら小児科 64 |
| 住宅地 | 110/四半期 | C院 | なし |
| 新興住宅地 | 270/四半期 | E院 | にじいろクリニック 58 |

### ★ポテンシャルを独占値に読み替えた

検証モデルの 150/130/110（四半期）は、**競合が居る現実の中で実際に得ていた数**で、
競合の存在が数字の中に畳み込まれていた。競合を盤上に出す以上、
畳み込まれていた分をほどかないと、同じ商売が半分の規模になってしまう
（実際、ほどく前は全ての遊び方が破綻した）。

開始時のシェアを掛けると検証モデルの水準に戻るように置いてある：

```
本町 260 × A院の初期シェア 58%（評判75・医師3 → 魅力97.5 対 本町内科70）≒ 150
駅前 350 × B院のシェア 37%（競合 82+64=146）                          ≒ 130
住宅地 110 × 100%（競合なし）                                          = 110
```

★**A院とD院は同じ商圏。** 承継は初日から患者が付いてくるが、
本院の商圏を食う。「安い・高い」ではなく「どこの客を取るか」の判断になる。

駅前は人通りが多い（ポテンシャル 130/四半期）が競合が2軒。
住宅地は競合が居ないがポテンシャルが低い（110）。**楽な商圏は儲からない。**

## 5. 表示

| 場所 | 出すもの |
|---|---|
| マップ | 競合のピン。自院と形と色を分ける。名前と強さ |
| マップの院の行 | シェア |
| 診療所画面「商圏」タブ | 商圏の内訳。自院と競合の魅力・シェアの棒 |

競合のピンは**自院より弱く描く**（塗りを持たせない）。
地図の主役は自院であって、競合は環境。

座標は sim が持たない。絵の都合なので UI 側（`MAP_POSITIONS` と同じ扱い）。

## 6. やらないこと

- 競合の価格・サービス競争。診療報酬は公定価格なので価格競争が起きない
- 競合の買収。M&A は承継（`CLINIC_SITES` の D院）で既に表現されている
- 患者の個別追跡。シェアは率であって、誰がどこへ行ったかは持たない
- 競合をAIで動かすこと（§3）
