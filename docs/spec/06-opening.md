# 開業

★**この層は検証されていない。** 01/02 のような表計算の裏付けは無い。
一般的な診療所開業の相場から置いた数字で、実際の到達点を測ってから調整する。

境界の守り方は 03-game.md と同じ：**既定シナリオはこの層を一度も通らない。**
`BASELINE_SCENARIO` は院を最初から持っていて `openClinic` の意思決定を1つも持たないので、
ここに書いた式は 1 回も評価されない。`baseline.golden.json` は動かない。

---

## 1. なぜ作り直したか

プレイテストで出た3つ：

- 最初から現金が 1.5 億あって、何を買っても痛くない
- 最初から A院に 3,200 人の患者が居て、**自分で作った実感が無い**
- 開業という、この業界でいちばん大きい意思決定が省略されていた

**開業は、このゲームで最初に効く遅延である。**
借りた金は10年ずっと利息を払い続けるし、内装は取り替えられない。
ここを省略すると、以後の判断が全部「余った金をどう使うか」になる。

## 2. 一般的な開業を再現する

診療所の新規開業でよく見る形：

| 項目 | 相場 | このゲームでの扱い |
|---|---|---|
| 自己資金 | 1,000〜2,000万円 | `OPENING_OWN_FUNDS = 1,000万` |
| 内装工事 | 1,500〜3,000万円 | 立地の `capex` に含む。内装グレードで倍率 |
| 医療機器 | 500〜5,000万円 | 科の `capexMultiplier` で倍率 |
| 運転資金 | 6ヶ月分 | 設備投資の 25%。**レセプトの入金が2ヶ月遅れる** |
| 開業融資 | 5,000万〜1億 | **足りない分を全部借りる**（下の式） |

自己資金だけでは絶対に足りない。**借りるかどうかは選択肢ではない。**
選べるのは「いくら借りることになるか」で、それを決めるのが立地・科・内装。

## 3. 開業資金の式

```
設備投資 = 立地の capex × 科の capexMultiplier × 内装の capexMultiplier
運転資金 = 設備投資 × 0.25
開業融資 = ceil( max(0, 設備投資 + 運転資金 − 手元現金) / 100 ) × 100
```

- 手元現金は**その月の頭の現金**（前月末残高）
- 100万円単位に切り上げる。円単位で借りる銀行は無い
- 借りたあとの手元現金 ≒ 運転資金。**開業直後は運転資金しか残らない**

2院目以降で現金が潤沢なら `開業融資 = 0` になり、そのまま自己資金で建つ。
式を分けていないので、**分院を出すたびに同じ計算が効く。**

### 既定シナリオを守る仕掛け

この式で決まった額は、開院した院の `ClinicConfig` に焼き付ける
（`capex` と `openingLoan`）。**焼き付いていない院は `CLINIC_CAPEX` / `CLINIC_LOAN`**
という検証済みの定数を通る。

`BASELINE_SCENARIO` の3院はシナリオが直接持っている `ClinicConfig` で、
`capex` も `openingLoan` も持たない。だから従来の経路を通り、
検証済みの資金繰りが 1 円も動かない。

★開院ループで `CLINIC_SITES` を引いてはいけない。
引くと、候補地の値段を変えた瞬間に検証済みの資金繰りが動く（実際そうなった）。

## 4. 内装グレード

**取り替えられない意思決定を1つ増やす。** 科と同じで、開院後に変えられない。

| グレード | 費用倍率 | 評判の落ち着き先 |
|---|---|---|
| 居抜き | 0.62 | 66 |
| 標準 | 1.00 | 75 |
| こだわり | 1.55 | 86 |

### なぜ「評判の落ち着き先」なのか

評判は 75（`BASELINE_REPUTATION`）へ回帰するだけで、**それを超えない**。
だから「開院時の評判を +10」にしても、数ヶ月で 75 に戻って何も残らない。

内装が効くのは**その院の評判が落ち着く先そのもの**を動かしたときだけ。
`nextReputation` の回帰先を院ごとに持たせる：

```
recovered = 前月の評判 + (その院の落ち着き先 − 前月の評判) × 回帰率
```

落ち着き先を持たない院は `BASELINE_REPUTATION` を使う。**恒等式。**

新規患者の式の分母（`potential × 評判 / 75`）は**全社共通の 75 のまま**。
あれは較正の基準点であって、その院の目標値ではない。
こだわり内装の院は 86 に落ち着くので、分母 75 に対して新規患者が 1.15 倍になる。

### 内装は評判の上限ではない

待ち時間が伸びれば、こだわり内装の院でも評判は落ちる。
**内装で買えるのは「放っておいたときの高さ」であって、混雑への耐性ではない。**

## 5. 本編の初期状態

| | 既定シナリオ（検証済み） | 本編 |
|---|---|---|
| 初期現金 | 15,000万 | **1,000万** |
| 開院済みの院 | A・B・C（開院月固定） | **無し** |
| A院の初期患者 | 3,200人 | **0人**（そもそも院が無い） |
| 最初の意思決定 | 医師の配置 | **どこで何科をどんな内装で開くか** |

`Scenario.initialCash` を足して、既定シナリオは `INITIAL_CASH` のまま置く。

本編は院を1つも持たずに始まる。**1ヶ月目にやることは開業しかない。**
開業しないまま月を送ると本部費だけが出ていくので、迷う余地は作らない。

## 6. 開院直後の立ち上がり

素の式のままだと、**患者ストックの時定数は 1/月次離脱率＝74ヶ月。**
0 から始めると10年経っても落ち着き先に届かず、開業がゲームとして成立しない。

検証モデルは A院を 3,200人 持って始まるので、この局面が一度も無かった。

実際の診療所は 1〜3年で埋まる。他院に通っている患者が乗り換えてくるからで、
その乗り換え圧は「まだ埋まっていない分」に比例する：

```
新規患者 = 落ち着いたときの新規 × 立ち上がり係数
立ち上がり係数 = 1 + 強さ × (1 − 埋まり具合)
埋まり具合 = 現在の患者 / （落ち着いたときの新規 ÷ 混んでいないときの離脱率）
```

### ★落ち着き先は動かない

微分方程式にすると `dS/dt = (1+強さ)(N − cS)` になり、
**時定数だけが 1/(1+強さ) になる。** 行き着く先は素の式と同じ。
速さを変えているのであって、上限を上げているのではない。

強さ 4 で 74ヶ月 → 約15ヶ月。3年でおおむね埋まる。

強さを持たない院（＝既定シナリオの3院）は係数 1 の恒等式。
`ClinicConfig.newPatientRamp` に焼き付ける。

### ★副作用：開院直後がいちばん詰まる

立ち上がり係数は空っぽのときに最大（5倍）なので、
**開院した月に患者がいちばん押し寄せる。**
枠を用意せずに開けると、そこで待ち時間が跳ねて評判が焼ける。
評判の回帰は 1ヶ月あたり 5.3% なので、**焼いた評判は4年残る。**

これは意図した挙動として残す。新しい医院が初日から90分待たせれば口コミは落ちるし、
「開院と同時に何人置くか」がこのゲーム最初の意思決定になるのは筋が通っている。

## 7. 開業据置と、破綻の判定

開業直後の診療所は**必ず債務超過に入る。**
自己資金 1,000万に対して設備投資が 5,500万で、初年度は赤字だから。

これは経営の失敗ではなく開業の形そのもので、開業融資も事業計画を前提に組まれている。
そこで銀行が資金を引き上げることはない。

だから破綻の判定を2箇所直した：

| | 前 | 後 |
|---|---|---|
| 開業据置 | 無し | **最初の開業から36ヶ月は数え始めない** |
| 数える条件 | 債務超過 | **債務超過かつ経常赤字** |

### なぜ「かつ経常赤字」なのか

純資産がマイナスでも黒字で回っている法人は、潰れているのではなく**返している最中**。
開業融資を借りた診療所はまさにこれで、経常が黒字化するのは3年目、
純資産が戻るのは5〜7年目。債務超過だけで殺すと、
**正しく立ち上げた人が正しさの途中で死ぬ。**

実際、この条件を入れる前は、どんな開き方をしても 13ヶ月目に全員が死んだ。

### 据置は最初の1回だけ

分院を出すたびに延びると、3年おきに安い院を建てて不死になる。
`openingGraceUntilMonth` は最初の開業でだけ立てて、以後は触らない。

### 既定シナリオへの影響

据置は `openClinic` の意思決定でしか立たないので、既定シナリオでは null のまま。
「かつ経常赤字」は既定シナリオの破綻月をずらしうるが、
**ゴールデンテストは診療所の数字だけを見ている**ので影響しない。

## 8. 目標値の測り直し

前の目標値（1.5億／8,000人／5,000万）は、A院を 3,200人 持って始まる形で測ったもの。
自己資金 1,000万から始める形に変えたら **50〜63ヶ月目で達成できてしまい**、
10年のうち半分が遊ばれないまま終わっていた。

4院まで広げた強い筋の 120ヶ月目の到達点を測り直して置き直した：

| 目標 | 前 | 後 | 一本に賭けたときの到達 |
|---|---|---|---|
| 資産家（個人資産） | 1.5億 | **2.5億** | 103ヶ月目 |
| 規模（通院患者） | 8,000人 | **11,000人** | 101ヶ月目 |
| 内部留保 | 5,000万 | **2億** | 107ヶ月目 |

3本を同時に狙うと 87ヶ月目に規模だけが届き、残り2本は 41% と 6% で終わる。
**同じ財布を取り合う**構造は保たれている。

## 9. やらないこと

- **開業を失敗させない。** 立地と科と内装の組み合わせで結果は変わるが、
  「開業した瞬間に詰む」選択肢は置かない。10年遊べないゲームになる
- **物件探しをゲーム化しない。** 候補地は最初から全部見えている
- **内装を後から変えられるようにしない。** 変えられると選ぶ意味が消える
- **開業融資の金利を立地で変えない。** 見えない差を増やすと説明できなくなる
