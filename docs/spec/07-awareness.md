# 集患と認知度

★**この層は検証されていない。** 表計算に対応する列が無い。
実際の到達点を測ってから置いた数字。

境界の守り方はこれまでと同じ：**既定シナリオはこの層を一度も通らない。**
認知度は「開業で建てた院」だけが持ち、シナリオが直接持っている院は常に 1。
`baseline.golden.json` は動かない。

---

## 1. なぜ作るか

プレイテストで出た指摘：**「集患に全く困らないのがおかしい。」**

そのとおりだった。それまでの新規患者は

```
新規患者 = ポテンシャル × 評判/75 × シェア × 立ち上がり係数
```

で、この4つのうち**プレイヤーが動かせるのは待ち時間経由のシェアだけ**。
医師を置いて枠を空ければ、あとは黙っていても商圏のぶんだけ患者が流れ込む。
開業直後ですらそうで、**「患者が来ない」という局面が1度も存在しなかった。**

実際の開業でいちばん怖いのはそこ。設備も医師も揃っているのに患者が来ない。

## 2. 認知度

院ごとのストック変数 0〜1。**その商圏の人が、その医院を知っているか。**

```
新規患者 = ポテンシャル × 評判/75 × シェア × 認知度 × 立ち上がり係数
```

評判とは別物であることが肝。

| | 評判 | 認知度 |
|---|---|---|
| 何を表すか | 知っている人がどう思っているか | そもそも知られているか |
| 上げ方 | 待たせない | 広告・口コミ |
| 落ち方 | 待たせると削れる | 広告をやめると落ちる |
| 効き方 | シェア（取り合いに勝つ） | 新規患者の絶対量 |

**評判が満点でも、知られていなければ誰も来ない。**

### 落ち着き先

```
到達可能な認知度 = 基礎 + 広告の到達 + 口コミ
  基礎     0.40   看板を出しているだけで届く範囲
  広告     0〜0.38  下の表
  口コミ   0.20 × min(1, 患者ストック / 落ち着き先)
```

上限は 0.98。**商圏を100%取ることはできない。**

```
翌月の認知度 = 認知度 + (到達可能な認知度 − 認知度) × 0.20
```

上げるのも落ちるのも同じ速さ。**広告をやめれば同じ速さで落ちる。**
外部関係と同じ「続けると育ち、やめると止まる」形。

### ★口コミが入っているのが効く

患者が増えると認知度が上がり、認知度が上がると患者が増える。
**正のフィードバックが1本入っている。**

だから序盤の1人が重い。何もしないと 0.40 に張り付き、
商圏の4割しか取れないまま10年が終わる。

## 3. 集患投資

院ごとに毎月決める。4段階。

| 段階 | 月額 | 認知の到達 | 何をしているか |
|---|---|---|---|
| なし | 0 | 0 | 看板だけ |
| チラシ・看板 | 25万 | +0.15 | ポスティング、駅の看板 |
| Web広告 | 70万 | +0.28 | 検索広告、ポータル掲載、口コミサイト対策 |
| 大々的に | 160万 | +0.38 | 上に加えて交通広告・地域紙 |

**逓減する。** 25万で 0.15 なのに、160万でも 0.38 にしかならない。
6.4倍払って 2.5倍。金で殴り切れないようにしてある。

### ★開業直後がいちばん苦しい

患者が居ないから口コミが効かず、現金が無いから広告も打てない。
それでも打たなければ認知度が上がらず、患者が来ない。

**この矛盾がこのゲームの序盤。**
運転資金をどこまで広告に突っ込むかが、開業の最初の賭けになる。

## 4. 承継は認知度を引き継ぐ

| 立地 | 開院時の認知度 |
|---|---|
| 新規開業 | 0.15 |
| 承継（D院） | 0.60 |

承継が高いのは、患者だけでなく**看板と地域の記憶を引き継ぐ**から。
承継の値段（11,000万）が新規（5,500〜7,000万）より高い理由がここで1つ増える。

## 5. 既定シナリオを守る仕掛け

`ClinicConfig.initialAwareness` を持つ院だけが認知度を持つ。
持たない院は**認知度 1 の固定**で、式が素のまま残る。

`BASELINE_SCENARIO` の3院はシナリオが直接持っている `ClinicConfig` で、
`initialAwareness` を持たない。だから：

- 新規患者の式に掛かる係数は 1
- 集患投資は0円（`marketing` の行が立たない）
- `awareness.test.ts` の先頭がそれ自体を検証している

## 6. 会計での置き場所

P/L に `marketing`（広告宣伝費）の行を足す。販管費なので営業利益の上。

**資産計上しない。** 広告の効果は認知度というストックに乗るが、
それは会計上の資産ではない。減価償却させると
「打つのをやめても償却が続く」という嘘になる。

## 7. やらないこと

- **広告の種類をゲーム化しない。** 4段階の金額だけ。
  媒体ごとの効き方を作ると、正解探しのパズルになる
- **認知度を院をまたいで共有しない。** グループの知名度ではなく、
  その医院が知られているかを測っている
- **認知度で評判を代替しない。** 知られているだけの医院は
  待たせれば評判が落ちて、シェアで負ける
